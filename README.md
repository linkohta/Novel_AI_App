# novelai-app

NovelAI の画像生成 API にプロンプトを送信し、生成された画像を保存・閲覧するアプリです。Electron によるデスクトップ版と、Capacitor による Android 版があり、React + Vite で書かれたUI（`src/`）とAPIリクエスト組み立て（`shared/`）のソースコードを共有しています。

## 機能

- プロンプト・ネガティブプロンプト・モデル・サイズ・ステップ数・スケール・サンプラー・シードを指定した画像生成
- キャラクタープロンプト（複数キャラクター分のプロンプト／ネガティブプロンプト）の設定・有効/無効切り替え
- キャラクター名・作品名（任意）と、既存のプロンプトチャンク／プロンプトテンプレートを組み合わせてキャラクタープロンプトを追加する機能（`character (series)` 形式 + 選択した内容を連結して自動生成）
- プロンプトチャンク（よく使う語句）の保存・編集・挿入・削除
- プロンプトテンプレート（`(変数名)` 形式のプレースホルダーを任意個数含むプロンプトの保存・編集・削除、適用時に変数値をまとめて入力して反映）
- お気に入りアーティスト・お気に入りキャラクター（キャラ名＋作品名）の保存・編集・削除、フォーカス中のプロンプト欄への挿入、キャラクターは「キャラクター名で追加」欄への自動入力
- 左パネルの各機能セクションの折りたたみ表示（設定／プロンプト／プロンプトテンプレート／お気に入り／キャラクタープロンプト／モデル／連続生成）。開閉状態は保存され、次回起動時も復元される
- 連続生成（指定回数・間隔で同一プロンプトを連続生成し、`batch_<タイムスタンプ>/` フォルダに保存。中断可能）
- 設定の自動保存・復元
- 生成結果のプレビューと履歴サムネイル表示
- 保存フォルダを開く機能（Android版では最新画像の共有機能として動作）
- 画像の保存先フォルダを設定画面から任意のフォルダに変更する機能（Electron版のみ。既定値は「ドキュメント」フォルダ配下の `NovelAI/output/`）
- 日本語化されたメニューバー（Electron版のみ）
- 「生成する」ボタンの常時表示（左パネルをスクロールしても画面下部に固定）

## セットアップ

```
npm install
```

## デスクトップ版（Electron）の起動

```
npm start
```

起動後、アプリ左パネルの「NovelAI API キー」に persistent token を入力してください。

## Android版（Capacitor）のビルド・実行

Android Studio と Android SDK がインストールされたマシンで作業してください。

```
npm run cap:sync         # src/ を vite build でビルドし、www/ の内容を Android プロジェクトへ同期
npm run cap:open:android # Android Studio で android/ プロジェクトを開く
```

Android Studio が開いたら、実機またはエミュレータを選択して実行してください（Run）。UI (`src/`) やAPIリクエスト組み立て (`shared/novelai.mjs`) を変更した場合は、`npm run cap:sync` を再実行してAndroidプロジェクトに反映してから実行し直してください。

初回のみ `npx cap add android` は実行済みです（`android/` ディレクトリがネイティブプロジェクトの実体です）。

## デスクトップ版の単独アプリ化（ビルド）

`npm install` した環境でのみ動く `npm start` とは別に、他のPCでも実行できる単独の実行ファイルを作成できます。

```
npm run dist      # 実行中のOS向けにビルド（dist/ に出力）
npm run dist:win  # Windows向けにNSISインストーラー(.exe)とポータブル版(.exe)を明示的にビルド
```

ビルドが終わると `dist/` 配下に以下が生成されます。

- `dist/NovelAI 画像生成 Setup <version>.exe` — インストーラー（推奨。スタートメニューに登録される）
- `dist/NovelAI 画像生成 <version>.exe` — インストール不要のポータブル版（このexe単体で起動可能）
- `dist/win-unpacked/` — 展開済みのアプリ一式（デバッグ用途）

## 使い方

1. プロンプト／ネガティブプロンプトを入力する。
2. 必要に応じて「＋ キャラクターを追加」でキャラクターごとのプロンプトを追加する。キャラクター名（と任意で作品名）が分かっている場合は、「キャラクター名」「作品名（任意）」欄に入力し、必要であれば「組み合わせるチャンク／テンプレート」で既存のプロンプトチャンクやプロンプトテンプレートを選択して「キャラクター名で追加」をクリックする。`character (series)` 形式のプロンプトに、選択した内容がカンマ区切りで連結されたカードが自動生成される（選択したテンプレートに変数がある場合は、追加前に変数入力ダイアログが開く）。
3. よく使うプロンプトは「プロンプトを保存」でチャンクとして保存し、チップをクリックして再利用できる。
3-2. 変数を含むプロンプトの型は「プロンプトテンプレート」に保存できる。本文中に `(変数名)` の形式で任意個数の変数を埋め込み、「テンプレートを保存」で保存する。一覧の「適用」をクリックすると変数の入力ダイアログが開き、値を入力して「反映」すると、直前にフォーカスしていたプロンプト欄（プロンプト／ネガティブプロンプト／各キャラクター欄）の内容が置き換わる。
3-3. よく使うアーティストやキャラクターは「お気に入り」に保存できる。アーティストは名前のみ、キャラクターは名前＋作品名（任意）で保存する。各チップの「挿入」をクリックすると直前にフォーカスしていたプロンプト欄に追加され、キャラクターのチップは「テンプレへ」をクリックすると「キャラクタープロンプト」セクションの「キャラクター名で追加」欄に自動入力される（そのままチャンク／テンプレートと組み合わせてキャラクターを追加できる）。
4. モデル・サイズ・ステップ数などを設定し、「生成する」をクリックする。「生成する」ボタンは画面下部に固定されており、パネルをスクロールしても常にクリックできる。
5. 生成された画像は「ドキュメント」フォルダ配下の `NovelAI/output/` に保存される（メニューの「ファイル」→「保存フォルダを開く」からも開ける）。「設定」セクションの「画像の保存先フォルダ」から「参照...」で任意のフォルダに変更できる（Electron版のみ。「既定に戻す」で元に戻せる）。
6. 同じ設定で複数枚生成したい場合は「連続生成」欄で回数と間隔（秒）を指定し、「連続生成する」をクリックする。画像は `NovelAI/output/batch_<タイムスタンプ>/` にまとめて保存され、「中断する」でいつでも停止できる。
7. 左パネルの各機能（設定／プロンプト／プロンプトテンプレート／お気に入り／キャラクタープロンプト／モデル／連続生成）はタイトルをクリックすると折りたたみ・展開できる。開閉状態は自動保存され、次回起動時も同じ状態で開く。

## 注意事項（連続生成について）

NovelAIの画像生成は1回ごとにAnlas（有料トークン）を消費し、無料枠にも制限があります。連続生成機能を使う際は、消費されるAnlas量と、短時間の大量リクエストによるレート制限・利用規約上のリスクを理解した上で利用してください。本アプリでは各生成の間に待機時間を挟む設計とし、既定値からむやみに間隔を詰めないことを推奨します。

## 開発

UIを素早く確認しながら開発したい場合は `npm run dev`（[electron-vite](https://electron-vite.org/)）を使えます。`main.js`/`preload.js`/`src/`をHMR付きでビルドし、実際のElectronアプリを自動起動するため、`window.api`は本物のIPC経由で動作します（画像生成やファイル保存もそのまま試せます）。

コードを変更したら、コミット前に以下でフォーマット・静的検査を行ってください。

```
npm run format  # Prettier で自動整形
npm run lint    # ESLint で検査
```

詳細な開発ルールや内部構成は [CLAUDE.md](./CLAUDE.md) を参照してください。
