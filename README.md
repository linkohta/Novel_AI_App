# novelai-app

NovelAI の画像生成 API にプロンプトを送信し、生成された画像を保存・閲覧するアプリです。Electron によるデスクトップ版と、Capacitor による Android 版があり、React + Vite で書かれたUI（`src/`）とAPIリクエスト組み立て（`shared/`）のソースコードを共有しています。全体を TypeScript（strict）で記述しています。

## 機能

- プロンプト・ネガティブプロンプト・モデル・サイズ・ステップ数・スケール・サンプラー・シードを指定した画像生成（Quality Tags自動追加のON/OFFも切り替え可能）
- キャラクタープロンプトの複数設定（キャラクター名・作品名からの自動生成、既存のプロンプトチャンク／プロンプトテンプレートとの組み合わせにも対応）
- プロンプトチャンク・プロンプトテンプレート（`"変数名"` プレースホルダー対応）・お気に入りアーティスト／キャラクターの保存・編集・挿入・削除
- 左パネルの各機能セクションの折りたたみ表示（開閉状態は次回起動時も復元）
- 連続生成（同一プロンプトを指定回数・間隔で連続生成し `batch_<タイムスタンプ>/` に保存）
- 複数プロンプト連続生成（プロンプト・ネガティブプロンプト・枚数・キャラクタープロンプトの組を行ごとに指定し、上から順に連続生成。生成画像は `queue_<タイムスタンプ>/` にまとめて保存）と、そのリスト全体をテンプレート化できる複数プロンプトテンプレート
- 設定の自動保存・復元（APIキー・各種パラメータ・キャラクタープロンプト・連続生成のリストなど、画面上のほぼすべての入力状態が対象）
- NovelAIで生成されたPNG画像から、埋め込まれた生成情報（プロンプト・パラメータ・キャラクタープロンプト）を読み取って自動入力する機能（「設定」セクション、複数プロンプト連続生成の各行の両方で利用可能）
- 生成結果のプレビューと履歴サムネイル表示
- NovelAI APIへ送信したプロンプト・パラメータのJSON保存（プロンプト単位で1個。テキストエディタ等でいつでも確認可能）
- 保存フォルダを開く機能（Android版では最新画像の共有機能として動作）、保存先フォルダの変更（Electron版のみ）
- 「Anlas / Opus残量を確認」ボタンでNovelAIアカウントの残量・無料生成枠を確認できる機能
- 日本語化されたメニューバー（Electron版のみ）、画面下部に常時表示される「生成する」ボタン

機能の詳細な仕様（各パラメータの意味やUI操作の細かい挙動、内部実装との対応）は [CLAUDE.md](./CLAUDE.md) を参照してください。

## セットアップ

```
npm install
```

## デスクトップ版（Electron）の起動

```
npm start
```

起動後、アプリ左パネルの「NovelAI API キー」に persistent token を入力してください。

## Android版（Capacitor）のビルド・実行

Android Studio と Android SDK がインストールされたマシンで作業してください。

```
npm run cap:sync         # src/ を vite build でビルドし、www/ の内容を Android プロジェクトへ同期
npm run cap:open:android # Android Studio で android/ プロジェクトを開く
```

Android Studio が開いたら、実機またはエミュレータを選択して実行してください（Run）。UI (`src/`) やAPIリクエスト組み立て (`shared/novelai.mts`) を変更した場合は、`npm run cap:sync` を再実行してAndroidプロジェクトに反映してから実行し直してください。

初回のみ `npx cap add android` は実行済みです（`android/` ディレクトリがネイティブプロジェクトの実体です）。

## デスクトップ版の単独アプリ化（ビルド）

`npm install` した環境でのみ動く `npm start` とは別に、他のPCでも実行できる単独の実行ファイルを作成できます。

```
npm run dist      # 実行中のOS向けにビルド（dist/ に出力）
npm run dist:win  # Windows向けにNSISインストーラー(.exe)とポータブル版(.exe)を明示的にビルド
```

ビルドが終わると `dist/` 配下に以下が生成されます。

- `dist/NovelAI 画像生成 Setup <version>.exe` — インストーラー（推奨。スタートメニューに登録される）
- `dist/NovelAI 画像生成 <version>.exe` — インストール不要のポータブル版（このexe単体で起動可能）
- `dist/win-unpacked/` — 展開済みのアプリ一式（デバッグ用途）

## 使い方

1. プロンプト／ネガティブプロンプトを入力する。必要に応じて「＋ キャラクターを追加」でキャラクターごとのプロンプトを追加する（「キャラクター名で追加」からキャラクター名・作品名や既存のチャンク／テンプレートを組み合わせて自動生成することもできる）。
2. よく使うプロンプトは「プロンプトチャンク」に、変数を含むプロンプトの型は「プロンプトテンプレート」（本文に `"変数名"` を埋め込む）に、よく使うアーティスト・キャラクターは「お気に入り」に、それぞれ保存して再利用できる。挿入・適用はいずれも、直前にフォーカスしていたプロンプト欄（プロンプト／ネガティブプロンプト／各キャラクター欄）に反映される。
3. モデル・サイズ・ステップ数などを設定し、画面下部に固定表示された「生成する」をクリックする。
4. 生成された画像は「ドキュメント」フォルダ配下の `NovelAI/output/` に保存される（「設定」セクションから任意のフォルダに変更可能。Electron版のみ）。同じフォルダに保存される `.json` ファイルで、その画像の生成に実際に使われたプロンプト・パラメータを確認できる。
5. 同じプロンプトで複数枚生成したい場合は「連続生成」、複数の異なるプロンプトを順番に生成したい場合は「複数プロンプト連続生成」（行ごとにプロンプト・枚数・キャラクタープロンプトを指定）を使う。それぞれ回数・間隔（秒）を指定して開始し、「中断する」でいつでも停止できる。よく使う複数プロンプトの組み合わせは「複数プロンプトテンプレート」として保存できる。
6. 左パネルの各機能セクションはタイトルをクリックすると折りたたみ・展開でき、開閉状態は次回起動時も復元される。

より詳しい操作手順（各ダイアログの挙動やキャラクター名での自動生成ルールなど）は [CLAUDE.md](./CLAUDE.md) の「機能」を参照してください。

## 注意事項（連続生成について）

NovelAIの画像生成は1回ごとにAnlas（有料トークン）を消費し、無料枠にも制限があります。連続生成機能（同一プロンプトの連続生成・複数プロンプト連続生成のいずれも）を使う際は、消費されるAnlas量と、短時間の大量リクエストによるレート制限・利用規約上のリスクを理解した上で利用してください。本アプリでは各生成の間に待機時間を挟む設計とし、既定値からむやみに間隔を詰めないことを推奨します。

## 開発

UIを素早く確認しながら開発したい場合は `npm run dev`（[electron-vite](https://electron-vite.org/)）を使えます。`main.ts`/`preload.ts`/`src/`をHMR付きでビルドし、実際のElectronアプリを自動起動するため、`window.api`は本物のIPC経由で動作します（画像生成やファイル保存もそのまま試せます）。

`npm start` / `npm run dist` 等の本番パイプラインでは、`vite build`（`src/` → `www/`）に加えて `tsc -p tsconfig.electron.json`（`main.ts`/`preload.ts`/`electron/**/*.ts`/`shared/novelai.mts` → `electron-dist/`）が実行されます（`npm run build:electron` で単独実行も可能）。Electronは `package.json` の `main` フィールドが指す `electron-dist/main.js`（コンパイル後のJS）を読み込むため、TypeScriptソースを直接実行することはありません。

コードを変更したら、コミット前に以下で型検査・フォーマット・静的検査を行ってください。

```
npm run typecheck    # tsc --noEmit でsrc/・electron/双方を型検査
npm run format        # Prettier で自動整形
npm run lint           # ESLint で検査
```

詳細な開発ルールや内部構成は [CLAUDE.md](./CLAUDE.md) を参照してください。
